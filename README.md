# 🎲 基隆美食地圖 (Keelung Food Roulette & Map)

一個專為基隆在地學生（如海大生）與遊客打造的互動式美食導航與盲盒抽籤網頁。解決每天「不知道要吃什麼」的選擇困難症，並支援即時營業時間過濾、步行/騎車時間計算、雙引擎地圖切換與殘酷二選一 PK 賽！

🔗 **線上展示網址 (GitHub Pages)**: https://hozongyu666.github.io/food-map/

---

## ✨ 核心功能特色

1. **🎲 雙模式命運選餐**
   * **命運轉盤模式**：從符合條件的店家隨機抽樣，搭配擬真音效與中獎漫天彩帶動畫。
   * **殘酷二選一 PK 賽**：透過趣味的兩兩對決淘汰賽，直覺選出當下最想吃的美味。
2. **🕒 智慧營業時段過濾與模擬器**
   * 內建 50+ 家基隆在地名店的真實營業時間（含跨夜營業與 24 小時店家）。
   * 支援**即時時間過濾**，或透過**時段模擬器**切換早餐、中餐、晚餐與宵夜場。
3. **🗺️ 雙引擎地圖與動態導航**
   * **互動雷達模式 (Leaflet)**：結合 OpenStreetMap，可隨時點擊地圖任意處變更出發點，自動繪製虛線路徑並計算距離與時間。
   * **Google Maps 實景模式**：一鍵切換內嵌式 Google 街景與導航。
4. **🚦 多維度進階篩選**
   * **商圈分類**：涵蓋中正路/三沙灣、祥豐街、海大/北寧路、正濱漁港/和平島、新豐街、深溪路/信義區及八斗子/潮境公園。
   * **移動方式**：支援「走路」與「騎車」兩種動態時間計算。
   * **📡 衛星雷達掃描**：一鍵線上動態抓取地圖周邊真實註冊店家。

## 🛠️ 技術架構

* **前端核心**：HTML5, CSS3 (Glassmorphism 毛玻璃視覺與彈簧懸浮互動特效), JavaScript (ES6+)
* **地圖與定位**：Leaflet.js, OpenStreetMap API, Overpass API
* **特效與多媒體**：Canvas Confetti (慶祝彩帶), Web Audio API (免外部音檔合成器)
* **部署平台**：GitHub Pages

---

## 🚀 快速開始與使用方式

1. 點擊進入線上網頁。
2. 在左側面板設定你的**出發點**（例如「海大校門口」）與**移動方式（走路/騎車）**。
3. 勾選 **「僅列出營業中店家」** 或調整時段模擬器。
4. 選擇 **轉盤抽籤** 或 **PK 擂台**，讓系統為你決定今天的美食！
